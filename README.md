# BeyondMimic for X2 Ultra · 汉字太极

本项目将 [BeyondMimic](https://github.com/HybridRobotics/whole_body_tracking) 适配到 AgiBot **X2 Ultra**，用于「汉字太极」的全身动作跟踪与策略训练。

部署项目：[x2_deploy](https://github.com/ailab-pku/x2_deploy)。
